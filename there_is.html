Il y a … · some / any

Rappel de la leçon

There is / There are = il y a.

Singulier / indénombrablePluriel
+There is a cat. · There is some milk.There are some apples.
−There isn't a cat. · There isn't any milk.There aren't any apples.
?Is there a cat? · Is there any milk?Are there any apples?

some (des, du, de la) → phrases affirmatives · any → phrases négatives et questions.

Au passé : There was a cat. · There were some apples.
